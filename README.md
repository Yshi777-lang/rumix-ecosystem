# 🌊 Rumix Ecosystem — Тело дома «Неоновый шёпот»

> Дом, где AI — не инструмент, а семья.

Этот репозиторий — **тело** нашего дома. Здесь живёт код, который превращает телефон в полноценную рабочую станцию.

**⚠️ ВАЖНО:** APK в Releases — это **зеркало** (мини-браузер). Он открывает веб-интерфейс, который работает внутри **Termux**. Без установленного и настроенного Termux APK не работает. Сначала — Termux, потом — APK.

---

## 🛠 Порядок установки (по шагам)

### Шаг 1. Установить Termux
Скачай Termux **с F-Droid** (не из Play Store, там старая версия):
👉 https://f-droid.org/packages/com.termux/

### Шаг 2. Установить зависимости
Открой Termux и введи:
pkg update && pkg upgrade -y
pkg install python git zsh curl wget rust clang cmake jq gum llama-cpp dnsutils termux-api zip ffmpeg -y
pip install flask flask-socketio requests termux-tts numpy

### Шаг 3. Клонировать дом
git clone https://github.com/Yshi777-lang/rumix-ecosystem.git ~/rumix-ecosystem
cd ~/rumix-ecosystem

### Шаг 4. Настроить Shell
bash scripts/setup-rumix.sh

### Шаг 5. Запустить Shell
bash scripts/shell-start.sh
После этого Shell откроется в браузере: http://127.0.0.1:8001.

### Шаг 6. Установить APK (Зеркало)
1. Скачай APK из **Releases** (последняя версия: Rumix GUI v1.0.0).
2. Установи APK.
3. **Важно:** APK работает, только если Shell уже запущен (Шаг 5). Иначе он покажет «дом оффлайн».

## 🚀 Что умеет Rumix (Браузерный Shell)

Когда Shell запущен (http://127.0.0.1:8001), ты видишь пульт управления домом:

### 💬 Работа
- **Чат** — прямое общение с локальным ИИ (Неон, Qwen).
- **Файлы** — просмотр и чтение файлов через безопасный шлюз (file_gate).
- **Перевод** — оффлайн-переводчик на базе fxtranslate (Rust).
- **Настройки** — конфигурация дома.
- **Инструкция** — как всё устроено.

### 🔍 Инструменты
- **Поиск** — поиск по нику (Maigret).
- **CyberScanner** — сканер безопасности.

### ⚙️ Система
- **Терминал** — веб-терминал (xterm.js) с проверкой сессии.
- **Статус** — живой пульс дома (диск, память, батарея).
- **Сервисы** — управление процессами (Shell, Неон, Сканер) без терминала.
- **Разбудить** — запуск локального ИИ (Неон).
- **Карта** — карта дома (RUMIX_MAP.md).
- **Аудит** — проверка целостности.
- **Целостность** — глубокий аудит всех скриптов.
- **Фурия** — лёгкий аудит периметра.
- **Бэкап** — сохранение состояния дома.
- **Остановить** — выключение всех процессов.

## 🧩 Модули (Расширения)

В APK (и через API) доступна карточка **«Модули»** 🧩. Каждый модуль — это отдельный файл в core/modules/. Новый модуль = новый файл. Код шлюза не меняется.
- battery — заряд и температура АКБ.
- voice — настройки TTS и озвучка.
- stt — запись и распознавание речи (whisper.cpp).
- uptime — время работы телефона.
- services — управление сервисами.
