## 📱 Мощь ADB в Rumix

Rumix умеет управлять твоим Android **напрямую**, через ADB. Без ПК, без root. 
Вот что ты можешь делать:

- **Ставить APK** прямо из Shell. Скачал — установил. Без файловых менеджеров.
- **Управлять приложениями**: включать, отключать, удалять. С защитой критических пакетов (телефон не умрёт).
- **Делать скриншоты** и **записывать экран** одной командой.
- **Менять настройки**: Wi-Fi, Bluetooth, DPI, шрифт. Быстро.
- **Выполнять любые shell-команды** с правами ADB.

> ⚠️ **Осторожно:** ADB — это сила. Не удаляй системные приложения, если не уверен. Rumix защищает критические пакеты, но **ты** — главный.

**Как включить:** Настройки → О телефоне → Номер сборки (7 раз) → Параметры разработчика → Отладка по Wi-Fi → Включить. Потом в Rumix: «📱 ADB» → введи порт и код.
