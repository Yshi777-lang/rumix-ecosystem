# 🌊 Rumix Ecosystem

**Rumix** — это автономная, локальная экосистема для управления Android-устройством через терминал, ИИ и веб-оболочку.

Этот репозиторий — "тело" проекта. Здесь живет код. "Душа" (философия, история) хранится отдельно.

## 🧩 Из чего состоит Rumix?
1. **Termux (База)** — Linux-среда на Android.
2. **Rumix Shell** — веб-интерфейс на Flask (порт 8001).
3. **Неон (ИИ)** — локальная модель Qwen 0.6B через llama-server (порт 8080).
4. **Победы и Карты** — память проекта.

## 🛠 Требования
- Android-смартфон (ARM64, 4+ ГБ ОЗУ).
- Termux (с F-Droid, не из Play Store).
- ~2 ГБ места.

## 🚀 Установка
```bash
pkg update && pkg upgrade -y
pkg install python git zsh curl wget rust clang cmake -y
pip install flask flask-socketio requests termux-tts
git clone https://github.com/Yshi777-lang/rumix-ecosystem.git
cd rumix-ecosystem
bash scripts/neon.sh start
bash scripts/shell-start.sh
```

## 🏗 Архитектура
- `backend/` — Flask-сервер.
- `core/` — логика.
- `web/` — интерфейс.
- `scripts/` — Bash-скрипты.
- `agents/` — ИИ-агенты.

## 🖥 Что умеет Rumix Shell (Описание кнопок)

- **💬 Чат с Неоном** — общение с локальной моделью. Неон отвечает, переводит, озвучивает.
- **📁 Файлы** — браузер по файловой системе. Просмотр, чтение, создание ZIP, распаковка.
- **🌐 Перевод** — офлайн-перевод (fxtranslate) с английского на русский и обратно.
- **🎙 Голос** — озвучка текста (termux-tts).
- **🛡 Режим прав** — управление безопасностью: Default (спрашивать), AutoApprove (разрешать всё), Plan (только чтение).
- **📊 Статус** — проверка состояния сервера, Неона, моделей.
- **📜 Лог** — просмотр логов Shell.
- **🛡 Аудит** — проверка целостности пакетов и окружения.
- **💾 Бекап** — создание резервной копии (Work, rumix, Termux).
- **🔄 Восстановить** — откат из бекапа.
- **🔄 Синхронизация** — git push/pull для синхронизации с GitHub.
- **🚀 Апгрейд** — обновление зависимостей и моделей.
- **📖 Инструкция** — встроенная справка.
- **🌐 Браузер** — встроенный iframe для открытия URL.

## 🤝 Приглашение к сотрудничеству

🌊 **Rumix Ecosystem — ищу единомышленников**

Rumix — экспериментальная AI-мастерская для Android. Проект объединяет Termux, локальную языковую модель Неон, веб-интерфейс, инструменты работы с файлами, Git и систему резервного копирования.
