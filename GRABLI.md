## 1. Синхронизация блокирует Flask
**Что случилось:** `sync-all.sh` запускался прямо в запросе Flask. Если `git pull` ждал — Flask зависал.
**Как починили:** `sync-all-bg.sh` — запускает синхронизацию в фоне (`nohup`).
**Не делать:** Не запускать долгие скрипты прямо в запросе. Только в фоне.

## 2. Полноэкранные окна сломали Shell
**Что случилось:** Мы пытались сделать `view-*` полноэкранными. Перепутали `loadView`, `nav`, `view-*`. Всё съехало.
**Как починили:** Откатили `index.html` к `10c0e57` (рабочая версия).
**Не делать:** Не менять `loadView` без бэкапа. Сначала — план, потом — код.

## 3. Termux удалён — дом потерян
**Что случилось:** Termux удалён. `/home/` исчез. `Work`, `rumix`, `rumix-ecosystem` — пропали.
**Как починили:** Восстановили из бэкапа (`~/storage/downloads/rumix-backup-...`) и GitHub.
**Не делать:** Не удалять Termux. Если удалил — не паниковать. Бэкап + GitHub спасут.

## 4. `llama-server` не было
**Что случилось:** После переустановки Termux `llama-server` отсутствовал. `neon.sh` не работал.
**Как починили:** `pkg install llama-cpp` (готовый бинарник).
**Не делать:** Не собирать `llama.cpp` из исходников. Есть готовый пакет.
## 5. `%F{magenta}` в промпте
**Что случилось:** После восстановления `.zshrc` промпт показывал `%F{magenta}` и `%1~`.
**Как починили:** `sed` убрал `%F{}` и `%1~`, добавили `PROMPT_SUBST` и `vcs_info`.
**Не делать:** Не копировать `.zshrc` с другой темы. Проверять промпт после восстановления.

## 6. `/tmp` только для чтения
**Что случилось:** `curl -o /tmp/...` → `Permission denied`.
**Как починили:** Используем `~/` (домашнюю папку).
**Не делать:** Не писать в `/tmp`. В Termux он read-only.

## 7. `heredoc` рвётся
**Что случилось:** `cat > file << EOF` обрывается на середине. Termux/чат ломают.
**Как починили:** Пишем через `nano` (частями) или `printf` (одной строкой).
**Не делать:** Не использовать `heredoc` для длинных текстов. Только `nano` или `printf`.

## 8. `base64` сломался
**Что случилось:** `base64.b64decode` → `UnicodeDecodeError`.
**Как починили:** Отказались от base64. Вставляем через `nano`.
**Не делать:** Не использовать base64 для README/текстов. Только `nano`.

## 9. Чего не делать (общие правила)
1. **Не ломать — выращивать.** Сначала бэкап, потом правка.
2. **Один кирпич — проверка — следующий.** Не менять всё сразу.
3. **`nano` вместо `heredoc`.** Длинные тексты — только частями.
4. **Не трогать `loadView` без плана.** Это — сердце Shell.
5. **Не удалять Termux.** Если удалил — бэкап + GitHub.
6. **`pkg install` вместо сборки из исходников.** Готовое — лучше.
7. **`~/` вместо `/tmp`.** Termux не любит `/tmp`.
8. **Бэкап перед хирургией.** Всегда.
